# AgentLinkOps plugin marketplace for Claude Code

```
/plugin marketplace add sunlover7/agentlinkops-marketplace
/plugin install agentlinkops@agentlinkops
```

One plugin: the AgentLinkOps skill pack with its hosted MCP server entry (`.mcp.json`). The plugin source is the public CLI repository, https://github.com/sunlover7/agentlinkops-cli, released as `agentlinkops` on npm. Documentation: https://docs.agentlinkops.com/quickstart. Other agents: `npx -y skills add https://agentlinkops.com`.
